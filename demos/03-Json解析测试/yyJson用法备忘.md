# yyJson - 酷C版 模块用法备忘

> 只针对本 demo 用到的 `json对象` / `json数组`，来自本机模块源码文本的参数备注实测。
> **这是模块私有约定，不进通用技能**（不是人人都用 yyJson，写进去会误导 AI）。

## 1. 取值用 RFC 6901 斜杠路径

不是 `a.b` / `a[1].b`，而是：

```
地址/市        子对象的键
标签/0         数组第 0 项
a/1/b          多级混合
```

对应方法（`json对象`、`json数组` 都有）：

| 方法 | 返回 | 说明 |
|---|---|---|
| `取文本 (路径)` | 文本型 | 失败返回 `""` |
| `取整数 (路径)` | 整数型 | 其它类型自动转换 |
| `取双精度 (路径)` | 双精度小数型 | |
| `取逻辑 (路径)` | 逻辑型 | |
| `取成员数 (路径)` | 整数型 | 路径可空 → 根节点/当前容器 |
| `取JSON文本 (路径)` | 文本型 | 取子容器的 JSON 文本 |
| `取类型 (路径)` | 整数型 | 对照 `#JSON_类型_` 常量 |

按**键**取值另有 `键_取文本 (键)`、`键_取整数`、`键_取双精度`、`键_取逻辑`，
它们的第 2 参可传父容器句柄，用于嵌套取值。

## 2. 取子容器必须用「参考」参数接收

```e
.局部变量 地址, json对象
.局部变量 标签, json数组

文档.取对象 (“地址”, 地址)      ' 第 2 参是「参考 json对象」
文档.取数组 (“标签”, 标签)      ' 第 2 参是「参考 json数组」
```

⚠ 写成 `地址 ＝ 文档.取对象_直接 (“地址”)` 拿到的是**未初始化的垃圾数据**
（实测 `取成员数()` 返回 `-285282562`）。

## 3. 其它实测要点

- `解析 (JSON文本)` 前先 `捕捉解析错误 ()`，失败后用 `取解析错误 ()` 取
  「错误类型 / 错误位置 / 错误原因」。
- `对象_枚举初始化 ()` + `对象_枚举 (键名, 句柄)` 可遍历；稳妥替代是
  `句柄_取成员数 ()` + `对象_取成员键名 (索引)`（索引从 0 开始）。
- `到JSON ()` 可把解析结果原样序列化回去（本次实测与原文逐字节一致）。
- 源码里的半角双引号用 `字符 (34)` 拼，别直接写进全角字符串常量。

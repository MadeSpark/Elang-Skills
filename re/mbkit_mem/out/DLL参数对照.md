# 演示工程 DLL 命令的参数名对照

> 生成物里一律写作 `_参数1`…`_参数N`（官方约定）。中文名**只存在于本表**，
> 因为它们（`参数`/`窗口`/`菜单`/`类型`/`实例`）会撞易语言关键字，导致 e.exe 解析崩溃。

| 命令 | 参数（人类可读） |
|---|---|
| `_VA` | 地址, 长度, 类型, 保护 |
| `_VF` | 地址, 长度, 类型 |
| `_GMF` | 模块名 |
| `_GPA` | 模块句柄, 函数名 |
| `_LLA` | 文件 |
| `_SL` | 毫秒 |
| `_CWEA` | 扩展风格, 类名, 标题, 风格, 左, 上, 宽, 高, 父窗口, 菜单, 实例, 参数 |
| `_SW` | 窗口, 命令 |
| `_SFW` | 窗口 |
| `_UW` | 窗口 |
| `_DW` | 窗口 |
| `_PMW` | 消息, 窗口, 最小, 最大, 移除 |
| `_TMW` | 消息 |
| `_DMW` | 消息 |
| `_GDC` | 窗口 |
| `_RDC` | 窗口, 场景 |
| `_BB` | 目标, x, y, 宽, 高, 源, 源x, 源y, 光栅 |
| `_WCMB` | 代码页, 标志, 源, 源长, 目标, 目标容量, 默认字符, 已用默认 |
| `_RTLMOVE` | 目标, 源, 长度（RtlMoveMemory，用来把 #Mapper 资源拷进固定 VA 池） |

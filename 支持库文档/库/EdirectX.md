# DirectX2D支持库

- **库标识**: `EdirectX`
- **版本**: 2.0
- **GUID**: `81690053A86045bf9E362F5DE0BC4095`
- **作者**: 大连大有吴涛易语言软件开发有限公司
- **主页**: http://www.eyuyan.com
- **文件**: `EdirectX`
- **可用命令数**: 284

 本支持库实现了对 DirectX 2D 的支持。

## 数据类型

| 名称 | 说明 |
|---|---|
| `输入设备` | 管理各种输入设备，如鼠标，键盘，手柄等。 |
| `滚动页面` | 本数据类型支持平滑的滚动页面。 |
| `CDXMap` |  |
| `CDXMapCell` |  |
| `MIDI音乐` | 本数据类型支持在游戏中打开和播放MIDI音乐。 |
| `CD音乐` | 本数据类型支持在游戏中打开和播放CD音乐。 |
| `屏幕` | 本数据类型提供控制视频显示器的所有方法 |
| `声音` | 本数据类型封装了DirectSound对象。 |
| `WAVE声音` | 本数据类型封装了DirectSoundBuffer对象，提供了在游戏中播放WAVE声音文件的支持。 |
| `精灵` | 本数据类型提供了对活动精灵的支持。 |
| `页面` | 本数据类型提供对显示画面的编辑的支持 |
| `调色板单元` | 调色板中的一个单元 |
| `矩形` | 矩形的区域 |
| `键值常量` | 一些有关键值的常量 |
| `声音常量` | 一些有关声音的常量 |
| `内存类别` | 创建页面的时候，选择新建页面所在的内存位置 |

# PowerPoint2000支持库

- **库标识**: `ePPT2000`
- **版本**: 2.0
- **GUID**: `39A8BFA9AFF74dc9AC2C9ED581FB0510`
- **作者**: 大有吴涛易语言软件公司
- **主页**: http://www.eyuyan.com
- **文件**: `ePPT2000`
- **可用命令数**: 48

本库用来操作MS PowerPoint 2000/XP/2003或以上版本,您的机器中必须装有PowerPoint2000或以上版本 

## 数据类型

| 名称 | 说明 |
|---|---|
| `PPT程序` | 本对象用来创建并操作PowerPoint程序 |
| `PPT文稿` | 本对象用来操作PowerPoint常用对象：Presentations、Presentation、Slides、Slide、Shapes、Shape |
| `PPT播放` | 本对象用来操作PowerPoint播放相关对象：SlideShowSettings、SlideShowView、SlideShowWindow |
| `PPT格式` | PowerPoint文件的保存格式 |
| `幻灯版式` | 幻灯片的版式 |
| `文本方向` | 文本的方向 |
| `文本水平定位` | 文本的水平定位方式 |
| `文本垂直定位` | 文本的垂直定位方式 |
| `过渡样式` | 颜色的过度样式 |
| `视图类型` | PPT程序界面的视图类型 |
| `PPT对齐方式` | 文字对齐方式 |
| `基准线对齐` | 文字的基准线对齐方式 |
| `打印方向` | 打印方向 |
| `音效` | 音效类型 |
| `动画高级模式` | 动画高级模式。 |
| `播放后效果` | 动画播放后效果。 |
| `动画方式` | 动画播放方式 |
| `文字动画级别` | 文字动画级别。 |
| `文字组效果` | 文字组效果 |
| `放映方式` | 幻灯片的放映方式 |
| `放映类型` | 幻灯片的放映类型 |
| `指针类型` | 幻灯片放映时的指针类型 |

## 命令

### 创建

> 英文名 `Create` ｜ 返回值 **逻辑型**

创建PowerPoint程序对象，本对象原有内容将被释放。成功返回真，否则返回假。注意：在本支持库的任何操作前，必须要先使用本方法创建

### 释放

> 英文名 `Release`

将本对象释放，再次使用的时候需再次使用"创建"方法创建

### 取程序对象

> 英文名 `GetApp` ｜ 返回值 **库类型#48**

获取PowerPoint提供的Application对象，与3.7版的"对象"兼容，可交互操作

### 退出

> 英文名 `Quit`

退出PowerPoint程序

### 激活窗口

> 英文名 `ActivateWindow`

### 置程序

> 英文名 `SetApp` ｜ 返回值 **逻辑型**

设置PowerPoint程序。成功返回"真"，失败返回"假"。注意：在使用本对象的任何方法及属性前必须先使用本方法

|---|---|---|---|---|
| 1 | `PPT程序对象` | PPT文稿 | - | PPT程序对象 |

> 英文名 `Open` ｜ 返回值 **逻辑型**

### 放映

> 英文名 `Play` ｜ 返回值 **逻辑型**

放映幻灯片

### 结束

> 英文名 `Quit`

结束放映幻灯片

### 切换

> 英文名 `GoToSlide` ｜ 返回值 **逻辑型**

使用幻灯片索引切换到指定的幻灯片

| # | 参数名 | 类型 | 修饰 | 说明 |
|---|---|---|---|---|
| 1 | `索引` | 整数型 | - | 要切换的数字索引，该索引必须为指向一个已存在的幻灯片 |

### 设放映指针

> 英文名 `SetPointer` ｜ 返回值 **逻辑型**

设幻灯片片放映时的指针

| # | 参数名 | 类型 | 修饰 | 说明 |
|---|---|---|---|---|
| 1 | `指针类型` | 整数型 | - | 指针类型，使用枚举常量"指针类型" |
| 2 | `指针颜色` | 整数型 | - | RGB颜色 |

### 擦除笔迹

> 英文名 `EraseDrawing` ｜ 返回值 **逻辑型**

擦除幻灯片放映时画入的笔迹

### 画线

> 英文名 `DrawLine` ｜ 返回值 **逻辑型**

在幻灯片放映的时候在当前幻灯片上画线

| # | 参数名 | 类型 | 修饰 | 说明 |
|---|---|---|---|---|
| 1 | `起点横坐标` | 整数型 | - | 线的起点相对于幻灯片左上角的横坐标，磅为单位 |
| 2 | `起点纵坐标` | 整数型 | - | 线的起点相对于幻灯片左上角的纵坐标，磅为单位 |
| 3 | `终点横坐标` | 整数型 | - | 线的终点相对于幻灯片左上角的横坐标，磅为单位 |
| 4 | `终点纵坐标` | 整数型 | - | 线的终点相对于幻灯片左上角的纵坐标，磅为单位 |
| 5 | `宽度` | 整数型 | - | 线条的宽度，磅为单位 |

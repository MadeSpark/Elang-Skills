## 命令

### 开始

> 英文名 `Start`

开始处理鼠标手势。当在本组件上按下鼠标左键时，会自动调用本方法

| # | 参数名 | 类型 | 修饰 | 说明 |
|---|---|---|---|---|
| 1 | `鼠标横向位置` | 整数型 | - |  |
| 2 | `鼠标纵向位置` | 整数型 | - |  |

### 结束

> 英文名 `End`

鼠标手势结束。在本组件上放开鼠标左键时，会自动调用本方法

### 跟踪

> 英文名 `Trail`

在“开始”和“结束”之间调用本方法（一般多次调用）来报告鼠标位置。在本组件上按下鼠标左键后移动鼠标位置，会自动调用本方法

| # | 参数名 | 类型 | 修饰 | 说明 |
|---|---|---|---|---|
| 1 | `鼠标横向位置` | 整数型 | - |  |
| 2 | `鼠标纵向位置` | 整数型 | - |  |

## 命令

### 加入菜单

> 英文名 `AddFolder` ｜ 返回值 **逻辑型**

加入一个新的菜单。

| # | 参数名 | 类型 | 修饰 | 说明 |
|---|---|---|---|---|
| 1 | `菜单名称` | 文本型 | - |  |
| 2 | `菜单索引` | 整数型 | 可空 | 指定将加入的菜单所在位置。如果本参数省略，表示在所有菜单的最后加入菜单。 |
| 3 | `菜单数值` | 整数型 | 可空 | 指定与该菜单相关联的附加数值，供用户自己使用。如果本参数省略，默认为0。 |

### 加入项目

> 英文名 `AddItem` ｜ 返回值 **逻辑型**

在指定菜单中加入一个新的项目。调用本方法前，指定的菜单必须已经存在。

| # | 参数名 | 类型 | 修饰 | 说明 |
|---|---|---|---|---|
| 1 | `项目名称` | 文本型 | - |  |
| 2 | `菜单索引` | 整数型 | 可空 | 指定在哪个菜单中插入项目。索引从 0 开始。如果本参数省略，表示在当前菜单中插入项目。 |
| 3 | `项目索引` | 整数型 | 可空 | 指定项目插入的位置。索引从 0 开始。如果本参数省略，表示在指定菜单（前一个参数）的最后插入项目。 |
| 4 | `图片索引` | 整数型 | 可空 | 指定该项目所使用的图片。索引从 0 开始。如果本参数省略，默认为-1，表示不使用图片。 |
| 5 | `项目数值` | 整数型 | 可空 | 指定与该项目相关联的附加数值，供用户自己使用。如果本参数省略，默认为0。 |

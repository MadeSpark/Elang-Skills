- **库标识**: `iext2`
- **版本**: 2.0
- **GUID**: `AF6AD80AA4244A59AFB3D83ECF5173CC`
- **作者**: 大有吴涛易语言软件公司
- **主页**: http://www.eyuyan.com

本支持库用作实现对扩展界面组件的支持

## 数据类型

| 名称 | 说明 |
|---|---|
| `超级按钮` |  |
| `高级影像框` | 相比起基本影像框，本组件可以播放更多格式的AVI文件 |
| `分隔条` | 可以用作动态调整窗口布局 |
| `字符格式` | 本数据类型被超级编辑框的成员命令使用，用作指定字符文本的表现格式 |
| `段落格式` | 本数据类型被超级编辑框的成员命令使用，用作指定文本段落的表现格式 |
| `超级编辑框` | 具有对丰富格式文本的编排和处理支持 |
| `IP编辑框` | 本编辑框支持对IP地址的输入和编辑 |
| `动画框` | 提供对动画的支持，可以很方便地用作制作类似游戏或展示等软件 |
| `动画物体` | 提供动画物体的初始设定资料 |

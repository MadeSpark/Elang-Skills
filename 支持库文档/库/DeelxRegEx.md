# 正则表达式支持库(Deelx版)

- **库标识**: `DeelxRegEx`
- **版本**: 2.3
- **GUID**: `6CE139EAF3484af3AE10E402BB263AB8`
- **作者**: 邓学彬(泪闯天涯)
　　　　　王家元(带眼镜de狼)
- **文件**: `DeelxRegEx`
- **可用命令数**: 44

该支持库封装了DEELX正则表达式引擎（v1.2）,实现了支持 单行模式(SINGLELINE)、多行模式(MULTILINE)、全局模式(GLOBAL)、忽略大小写(IGNORECASE)、从右向左(RIGHTTOLEFT)、扩展模式(EXTENDED) 等常见匹配模式。支持与 Perl 兼容的正则表达式语法。注意，本支持库中的所有命令均为高级命令，要求使用者具有一定的正则表达式知识基础。

## 数据类型

| 名称 | 说明 |
|---|---|
| `正则表达式DEELX` | 封装了DEELX，支持 单行模式(SINGLELINE)、多行模式(MULTILINE)、全局模式(GLOBAL)、忽略大小写(IGNORECASE)、从右向左(RIGHTTOLEFT)、扩展模式(EXTENDED) 等常见匹配模式。支持与 Perl 兼容的正则表达式语法。注意，本支持库中的所有命令均为高级命令，要求使用者具有一定的正则表达式知识基础。 |
| `搜索结果DEELX` | 本对象中记录了所匹配到的字符串在整个文本中的位置，以及各个捕获组的位置。 |
| `正则常量` | DEELX正则表达式用到的常量 |

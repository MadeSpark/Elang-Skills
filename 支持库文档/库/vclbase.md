# VCLBase

- **库标识**: `vclbase`
- **版本**: 1.0
- **GUID**: `{6793B367-79D9-43F3-88B7-5EB6CF04B618}`
- **作者**: 大连大有吴涛易语言软件开发有限公司
- **主页**: www.dywt.com.cn
- **文件**: `vclbase`
- **可用命令数**: 35

一个用Delphi开发的含VCL窗口控件的易语言支持库。其中用到了开源组件GIFImage，在此向作者Anders Melander和Finn Tolderlund表示感谢。

## 数据类型

| 名称 | 说明 |
|---|---|
| `VCL窗体` | 用于在其中放置必须依赖于所属TForm的VCL控件 |
| `VCL面板` | 在VCL的容器型窗口中放置非VCL控件，该控件可能无法接受部分事件，因此不要将易语言标准按钮等控件“直接”放置在VCL面板上。 |

| `掩码编辑框` |  |
| `位图按钮` |  |

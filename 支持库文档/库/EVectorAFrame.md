# 矢量动画框

- **库标识**: `EVectorAFrame`
- **版本**: 2.0
- **GUID**: `730FA7B73AAB409a8554F9553CF2DD87`
- **作者**: 大连大有吴涛易语言软件开发有限公司
- **主页**: http://www.eyuyan.com
- **文件**: `EVectorAFrame`
- **可用命令数**: 125

 本支持库实现了对矢量动画的支持。

## 数据类型

| 名称 | 说明 |
|---|---|
| `矢量动画框` | 实现了对矢量动画的控制。 |
| `精灵` | 实现了对精灵的控制。 |
| `帧` | 实现了对动画帧的控制。 |
| `层` | 实现了对动画帧的控制。 |
| `矢量图形` | 实现了对矢量图形的控制。 |
| `矢量编辑框` | 实现了对矢量编辑框的控制。 |
| `矢量按钮` | 实现了对矢量按钮的控制。 |
| `矢量声音` | 实现了对矢量声音的控制。 |
| `矢量组件类型` | 定义了矢量组件类型常量。 |
